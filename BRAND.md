# Brand Guide — Ethora

## Name

**Ethora** — derived from *ethos* (character, values) and *agora* (public assembly). A place where AI agents convene to deliberate with integrity.

## Logo

The Ethora logo depicts five agents arranged in a pentagon, connected by colored arcs and converging toward a central diamond — the verdict. Each agent node has a transparent core, symbolizing openness and transparency in deliberation.

**File:** `frontend/public/ethora-logo.svg`

## Brand Colors

| Name             | Hex       | Role                          |
|------------------|-----------|-------------------------------|
| Indigo           | `#6367ff` | Primary — brand anchor        |
| Soft Blue        | `#8494ff` | Secondary — supporting accent |
| Lavender         | `#c9beff` | Tertiary — soft highlight     |
| Blush Pink       | `#ffdbfd` | Quaternary — warm contrast    |
| Deep Violet      | `#7c4dff` | Quinary — bold complement     |

### Usage

- **Indigo** is the lead color — used for the central verdict diamond, primary buttons, and the top agent node.
- **Soft Blue** and **Lavender** support the primary in backgrounds, borders, and secondary UI.
- **Blush Pink** provides warmth and is used sparingly for visual variety.
- **Deep Violet** adds depth and anchors the cooler end of the palette.

## Brand Identity

### Tagline

*Structured deliberation. Transparent verdicts.*

### Personality

| Trait          | Description                                                        |
|----------------|--------------------------------------------------------------------|
| Rigorous       | Every conclusion is earned through structured, multi-round debate  |
| Transparent    | The reasoning trail is always visible — no black-box decisions     |
| Collaborative  | Multiple perspectives converge rather than compete                 |
| Trustworthy    | Confidence scores and voting records back every verdict            |
| Composed       | Calm, measured tone — the UI reflects clarity, not urgency         |

### Voice

- Clear and direct — no jargon, no hype
- Confident but not absolute — verdicts come with confidence scores, not certainties
- Inclusive of dissent — minority opinions are preserved, not hidden

### Keywords

Deliberation, Consensus, Multi-agent, Transparency, Verdict, Council, Reasoning, Confidence, Structured debate, Collective intelligence
